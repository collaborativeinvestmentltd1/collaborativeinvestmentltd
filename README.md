## Overview

Collaborative Investment Ltd (CIL) is an Integrated Business Development & Investment Management company operating across multiple sectors in Nigeria. This is the official website repository.

## 🚀 Features

- **10-Pillar Ecosystem** - Showcase of all business divisions
- **Company Directory** - Overview of all CIL companies
- **News Section** - Latest announcements and updates
- **Partners Page** - Current partnerships and collaborations
- **Contact Form** - Real-time email functionality with Google SMTP
- **Career Opportunities** - Job listings across all sectors
- **Responsive Design** - Mobile-first, fully responsive layout

## 🛠️ Tech Stack

- **Backend:** Node.js with Express
- **Email:** Nodemailer with Google SMTP
- **Templating:** EJS (HTML)
- **Styling:** Custom CSS with Google Fonts
- **Icons:** Font Awesome
- **Hosting:** Render.com (recommended)
